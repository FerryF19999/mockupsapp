# Asset notes

- App icon, wordmark and Rio mascot: assets supplied by the user in the Nemu workspace and chat.
- Promo artwork (`assets/promo-nemu.png`), generated listing photos (`*-generated.jpg`), and fashion try-on outfit previews (`tryon-*.jpg` / `tryon-jacket.png`): generated for this prototype. Other product and food photographs: downloaded from Unsplash image URLs; see the [Unsplash License](https://unsplash.com/license).
- Interface icons: the icon subset in `assets/sprite.svg` is assembled from [Lucide](https://lucide.dev/icons/), an ISC-licensed open-source icon set. The full license is in `assets/lucide-LICENSE.txt`.
- Interface and screen layouts: original prototype composed for Nemu from the user's screenshots and design references. Pinterest was accessible only in its signed-out preview, so this uses the visible orange marketplace results as broad visual inspiration.

All catalog listings, restaurant details, prices and interactions on the screen are illustrative prototype content.

- Category 3D icons (`shopping_bags_3d.png`, `mobile_phone_3d.png`, `t-shirt_3d.png`, `house_3d.png`, `video_game_3d.png`): [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji), MIT license; see `assets/fluent-LICENSE.txt`. Chosen to match the Muse reference style; Muse’s exact source is not verified.
